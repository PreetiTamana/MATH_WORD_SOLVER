#  Math Word Problem Solver

A beginner-friendly Python project that solves simple math word problems and explains the reasoning step by step.

This project simulates basic AI-style reasoning by extracting numbers from natural language and generating a human-readable solution.

---

## 🚀 Features

* Extract numbers from text using Regular Expressions (Regex)
* Detect subtraction word problems
* Generate step-by-step explanations
* Dynamic person name extraction
* Interactive CLI interface
* Automated test cases
* Error handling for invalid inputs

---

## 🛠️ Technologies Used

* Python
* Regular Expressions (`re`)
* Functions
* Loops
* String Processing

## 📖 Example

### Input

```text
Sarah has 10 candies and gives away 4 candies.
```

### Output

```text
Step 1: Sarah starts with 10 apples.
Step 2: Sarah gives away 4 apples.

10 - 4 = 6

Answer: 6 apples
```

---

## 🔍 How It Works

1. Accepts a math word problem as input.
2. Extracts numbers using Regex.
3. Detects the operation from keywords.
4. Performs the calculation.
5. Generates a step-by-step explanation.
6. Displays the final answer.
